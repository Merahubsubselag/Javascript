====================================================================
      JAVASCRIPT PERFORMANCE & LAG DEBUGGING NOTES (DEVTOOLS)
====================================================================

1. LAG DO TARAH KE HOTE HAIN:
   - API Lag (Network Delay): Server se data aane mein time lagna.
     -> Check karne ki jagah: DevTools > Network Tab (Fetch/XHR).
   - Code Lag (Execution Delay): Data milne ke baad JS code/loop chalne mein time lagna.
     -> Check karne ki jagah: DevTools > Performance Tab.

--------------------------------------------------------------------

2. TIME KA HISAB (200ms RULE):
   - 1 Second = 1,000 ms (Milliseconds)
   - < 100 ms   : Instant (Turant response)
   - < 200 ms   : Green Zone (Smooth - User ko lag nahi dikhta)
   - > 500 ms   : Red Zone (Slow - Website hang mehsoos hoti hai)
   - Long Task  : Koi bhi JS code jo 50 ms se zyada Main Thread ko roke.

--------------------------------------------------------------------

3. PERFORMANCE TAB CHECK KARNE KE STEPS:
   Step 1: Chrome mein F12 dabayein -> "Performance" tab kholein.
   Step 2: Record (●) button dabayein.
   Step 3: Page par slow button/action click karein.
   Step 4: Stop button dabayein aur graph dekhein.

--------------------------------------------------------------------

4. GRAPH AUR TABS KO KAISE PADHEIN?
   - INP Number (Left side): Green (< 200ms) hona chahiye. Red matlab lag hai.
   - Bottom-up Tab: Sabse upar woh function dikhega jisne sabse zyada "Self time %" khaya hai (Culprit pakadne ke liye best).
   - Call Tree Tab: Start se End tak ka flow dikhata hai (Kisne kisko call kiya).
   - Event Log Tab: Timeline ke hisab se exact step-by-step execution dikhata hai.

--------------------------------------------------------------------

5. DEVTOOLS COLORS AUR TERMS KA MATLAB:
   - Yellow (Scripting) : JavaScript code chal raha hai (Fast ho ya slow, color yellow hi rahega).
   - Purple (Rendering) : HTML/CSS design calculate ho raha hai.
   - Green (Painting)   : Screen par colors/pixels draw ho rahe hain.
   - Minor GC           : Browser ka Garbage Collector (Memory saaf kar raha hai).
   - (anonymous)        : Bina naam wala arrow function () => {}.

--------------------------------------------------------------------

6. CODE LAG FIX (SHORT) KARNE KE 3 TARIKAY:
   1. Smart Logic / Data Structure: Nested loops hatakar "Set" ya "Map" use karein.
   2. Chunks (Time Slicing): Bade kaam ko setTimeout(..., 0) se chote hisson mein todein.
   3. Web Workers: Heavy calculation ko background thread par bhejein.

--------------------------------------------------------------------

7. CODE KE ANDAR EXACT TIME CHECK KARNE KA FORMULA:
   const start = performance.now();
   // Apna code yahan likhein
   console.log(`Time laga: ${(performance.now() - start).toFixed(2)} ms`);

====================================================================
