1. Global Execution Context (GEC)


Phase 1: Memory Creation Phase (GEC)

Jab code shuru hoga, toh JS engine memory allocate karega. Yahan par var aur let/const alag-alag tarike se behave karenge:
• age (var): Yeh Global Space mai store hoga aur iski value undefined set hogi.
• colors (let): Yeh ek special Script/Block Space mai store hoga. Isko memory toh milti hai, par yeh Uninitialized rehta hai (ispe access karne par Error aayega, isi ko Temporal Dead Zone kehte hain).
• user (const): Yeh bhi Script Space mai store hoga aur Uninitialized rahega.
• updateAge (function): Global space mai iska poora function body/code copy ho jayega.
• result (var): Global space mai undefined set hoga.

Phase 2: Code Execution Phase (GEC)

Ab code line-by-line chalega aur values assign karega:
• Line 1: age ki value undefined se badalkar 25 ho jayegi.
• Line 2: Heap memory mai ek array ["red", "blue"] banega, aur uska reference (address) colors variable ko milega. Ab yeh Temporal Dead Zone se bahar aa gaya.
• Line 3: Heap memory mai ek object { name: "Raj" } banega, aur uska reference user variable ko milega.
• Line 5-9: Function body ko skip kar diya jayega.
• Line 11: Jaise hi updateAge(age) call hua (jahan age ki value 25 paas ho rahi hai), JS engine GEC ko rokk kar ek naya Function Execution Context (FEC) banayega.

2. Function Execution Context (FEC)


Phase 1: Memory Creation Phase (FEC)

Ab sirf function ke andar ke maal-masale ke liye local memory banegi:
• newAge (Parameter): Isko local memory milega aur value undefined set hogi.
• factor (let): Local space mai memory milegi par yeh Uninitialized rahega (Temporal Dead Zone mai).
• double (var): Local space mai memory milegi aur value undefined set hogi.

Phase 2: Code Execution Phase (FEC)

Ab function ke andar ka code line-by-line chalega:
• Sabse pehle argument transfer hoga: newAge ki value badalkar 25 ho jayegi.
• Line 6: factor ko uski value 2 assign ho jayegi (ab yeh safe hai).
• Line 7: newAge * factor (25 * 2 = 50) calculate hoga aur double variable mai 50 store ho jayega.
• Line 8: return double; chalega, yaani yeh function 50 return karega.
• Function End: Return hote hi yeh pura FEC (Function box) memory se delte/destroy ho jayega.

3. Wapas GEC mai Return (Final Step)

• Control wapas Global context ke Line 11 par aayega.
• Function se jo 50 return hua tha, wo Global variable result mai assign ho jayega (uski value undefined se badalkar 50 ho jayegi).
• Poora program khatam hote hi or GEC program khatam hone par nahi, balki browser tab band hone par destroy hota hai.
