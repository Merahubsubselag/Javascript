3. 🎯 Project me sabse zyada kaam aane wale Top 10 Methods

Jab aap aage jaakar project banaoge, toh aapki list me se sirf ye 10-12 methods hi hain jo 95% time use honge:
1. length : String ki lambai check karne ke liye (Yeh property hai, function nahi) [mozilla.org].
2. toLowerCase() / toUpperCase() : Text ko chota ya bada karne ke liye (Search features me bohot kaam aata hai) [mozilla.org].
3. trim() : User jab form bharta hai, toh aage-piche ki faltu spaces hatane ke liye [mozilla.org].
4. includes() : Yeh check karne ke liye ki string me koi word maujood hai ya nahi (true/false deta hai) [mozilla.org].
5. split() : Ek lambi string ko todkar array banane ke liye [mozilla.org].
6. slice() : String ka ek chota tukda kaat kar nikalne ke liye [mozilla.org].
7. replace() / replaceAll() : Kisi word ko badal kar dusra word likhne ke liye [mozilla.org].
8. indexOf() : Kisi akshar ya word ki position (index) pata karne ke liye [mozilla.org].
9. startsWith() / endsWith() : Check karne ke liye ki string kis word se shuru ya khatam ho rahi hai [mozilla.org].
10. at() : Negative index use karke string ke aakhiri akshar ko aaram se nikalne ke liye (jaise str.at(-1)) [mozilla.org].

🎯 String Reverse Karne Ki 3-Step Trick

Maan lijiye aapka naam "Rahul" hai aur aapko ise "luhaR" banana hai:
javascript
let name = "Rahul";

// Step 1: .split("") use karke string ko tod kar Array banao
let arrayName = name.split(""); 
// Output: ["R", "a", "h", "u", "l"]

// Step 2: Array ke built-in .reverse() method se list ko ulta karo
let reversedArray = arrayName.reverse(); 
// Output: ["l", "u", "h", "a", "R"]

// Step 3: .join("") use karke array ko wapas jod kar String banao
let finalResult = reversedArray.join(""); 
// Output: "luhaR"

console.log(finalResult); // "luhaR"
Use code with caution.

🔥 Pro-Tip: Real Projects me ise ek single line me likha jata hai:

Jab aap pro ho jaoge, toh aapko alag-alag variables banane ki zaroorat nahi padegi. Aap teenon ko ek sath chain kar doge:

Use code with caution.

2. reverse(): Array ko ulta kiya.
3. join(""): Array se wapas String banaya.
