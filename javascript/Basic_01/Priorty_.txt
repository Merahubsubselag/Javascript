  }

    // Inner Class (Andar wali) - Naam ekdum SAME hai!

Q17. Class se zyada izzat function ko milti hai?
-> Haan! Compile time par function (Rank 2) pehle memory leta hai, class (Rank 3) baad mein. Function bina declare hue bhi chal jata hai, par class banti nahi toh crash ho jati hai.

Q18. Agar function ke andar se class call ho toh kya class pehle hui?
-> Nahi, priority wahi rahegii. Bas function ke andar ka code tab tak soya rehta hai jab tak tum use call nahi karte, isiliye code fatta nahi hai.

Q19. Agar class ke andar hi bahar wala function call ho toh?
-> Agar class bante waqt (inline field mein) call kiya toh Error ❌. Agar class ke kisi method/constructor ke andar call kiya toh Safe ✅.

Q20. Agar class ke andar hi apna function bana kar call karein toh?
-> Bante waqt inline call kiya toh Error ❌ (Object taiyar nahi hota). Constructor ya method ke andar call kiya toh Safe ✅.

Q21. Constructor ke time bhi toh class ban rahi hoti hai, tab kyun nahi fati?
-> Kyunki constructor chalne se PEHLE hi JS class ka poora dhaanchan (structure) memory mein active kar chuka hota hai.

Q22. Par class pehle memory legi aur constructor baad mein na?
-> Nahi! Class aur uske andar ke saare functions (including constructor) ko memory ek saath, ek hi time par milti hai.

Q23. Jab class ka ek function doosre ko call kare toh kyun nahi fatti?
-> Kyunki dono function ek hi ghar (Prototype) ke hain aur dono bante waqt nahi chalte, balki object banne ke BAAD (jab sab ready ho) tab chalte hain.

Q24. Mtlb class ke function se class nahi fategi, par bahar wale se fat jayegi?
-> Ekdum sahi! Class ke bante waqt inline kuch bhi forcefully call karoge toh fategi. Par function/method ke andar daal doge toh soya rahega aur safe rahega.

Q25. Toh end mein class ko pehle memory mili ya function ko?
-> FUNCTION ko hamesha pehle memory milti hai (Rank 2) aur CLASS ko baad mein (Rank 3).

Q26. Class mein function declare hai toh object banne se pehle call hi nahi hoga na?
-> 100% Sahi! Function tabhi jagega jab object banega. Inline wale case mein tum object banne se pehle hi chalne ko bol rahe the, isliye fata tha.

Q27. Object banne par bhi kya same name par function ko pehle memory milti hai? Aur inner class ka kya?
-> Run-time (object banne) par rule badal jata hai! Same name par variable/property jeet jaati hai aur function ko override kar deti hai. Aur inner class mein JS hamesha local scope (paas wale) ko pehle uthata hai.
