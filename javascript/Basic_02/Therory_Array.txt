 Dense vs. Sparse Array (Memory ke hisab se)

Interview mein ye depth check karne ke liye pucha jata hai.
• Dense Array: Jismein saare elements lagatar (continuous) index par hon, 
koi bhi slot khali na ho. Ye bohot fast hota hai.
• Sparse Array: Jismein beech mein khali jagah (gaps) ho.

Nested Array (Array ke andar Array / Matrix) Ko Access Karna
Jab array ke andar array hota hai, toh aapko do baar square brackets [][] lagane padte hain.
 Pehla bracket outer array ke index ke liye, aur dusra andar wale inner array ke index ke liye

. Array of Objects Ko Access Karna

Jab array ke andar objects hote hain, toh pehle aapko square bracket [index] 
se object tak pahunchna hota hai, aur phir dot
 . (dot notation) ya bracket ['key'] se object ke andar ki property nikalni hoti hai:

 const users = [
  { id: 1, name: "Rahul", skills: ["JS", "React"] }, // Index 0
  { id: 2, name: "Amit", skills: ["Python", "Node"] }   // Index 1
];

console.log(users[0].name); // Output: "Rahul"

// Dusre user ki skills (jo khud ek array hai) ka pehla skill nikalna hai:

Yaad Rakhne Ka Golden Rule:

• Jab tak square bracket [] chal raha hai, aap index (number) de rahe ho.
• Jaise hi dot . lagaya ya string key di ['name'], aap object ki property access kar rahe ho.
• Agar kuch samajh na aaye, toh bich mein console.log() lagakar ek-ek step check kar lo ki us step par kya mil raha hai!

---------------------- JavaScript array-copy operations Deep copies. ---------


One way to make a deep copy of a JavaScript object, if it can be serialized, is to use JSON.stringify() 
to convert the object to a JSON string, and then JSON.parse() 
to convert the string back into a (completely new) JavaScript object:

const ingredientsList = ["noodles", { list: ["eggs", "flour", "water"] }];
const ingredientsListDeepCopy = JSON.parse(JSON.stringify(ingredientsList));

Because a deep copy shares no references with its source object,
 any changes made to the deep copy do not affect the source object.

 // Change the value of the 'list' property in ingredientsListDeepCopy.
ingredientsListDeepCopy[1].list = ["rice flour", "water"];
// The 'list' property does not change in ingredients_list.
console.log(ingredientsList[1].list);
// Array(3) [ "eggs", "flour", "water" ]
